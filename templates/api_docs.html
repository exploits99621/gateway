📚 API Documentation

Create Payment

URL: {{ gateway_url }}api/create

Method: POST

Headers:

X-API-Key: YOUR_API_KEY

Body (JSON):

{"amount": 100}

Response:

{
    "status": "success",
    "order_id": "ORD_20240101_ABC123",
    "amount": 100,
    "qr_code": "data:image/png;base64,...",
    "upi_id": "9817317740@fam"
}

Verify Payment

URL: {{ gateway_url }}api/verify

Method: POST

Headers:

X-API-Key: YOUR_API_KEY

Body (JSON):

{
    "order_id": "ORD_20240101_ABC123",
    "transaction_id": "1234567890"
}

Response:

{
    "status": "success",
    "message": "Payment verified"
}
